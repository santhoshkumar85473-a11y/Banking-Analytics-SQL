 Banking Analytics Using SQL

 Project Overview
This project uses SQL to analyze banking loan data and extract meaningful insights into loan distribution, financial performance, and repayment risk.

 Objectives
- Analyze banking loan data.
- Calculate key financial metrics using SQL aggregate functions.
- Examine loan distribution and performance.
- Identify default and delinquency patterns.
- Generate insights to support data-driven decisions.


 Tools and Technologies
- MySQL
- SQL
- Aggregate Functions
- GROUP BY and HAVING
- Joins and Subqueries
- Common Table Expressions (CTEs)
- Window Functions, where applicable
  
  
Skills Demonstrated
- SQL Data Analysis
- Data Aggregation
- Financial KPI Calculation
- Data Filtering and Grouping
- Banking Data Analysis

 How to Run
1. Download the SQL file from this repository.
2. Open MySQL Workbench.
3. Create or select the required database.
4. Import or execute the SQL script.
5. Review the query results.
